# LeetCode 練習日誌

按日期記錄一次練習做了什麼、觀察到的能力與下次如何接續。這是練習過程日誌；每題的正式狀態以 [RECORD.md](RECORD.md) 為準，目前題目與下一步以 [SESSION_HANDOFF.md](SESSION_HANDOFF.md) 為準，完整程式與筆記留在 `solved/`。

## 記錄方式

- 每個實際練習日新增一節 `## YYYY-MM-DD`；同日再次練習就追加小節，不覆蓋已記錄內容。沒有練習的日期不用補空白日誌。
- 記下題號與題型、實際完成或中斷的事、已執行的驗證、使用者能獨立說明的部分、仍需提示的部分，以及下次第一步。證據不明時標示「未知」。
- 當天練習結束、切換練習階段或使用者要求回顧時更新。每題原始作答仍依 [WORKFLOW.md](WORKFLOW.md) 歸檔；日誌只放摘要和連結，不重複完整程式。
- 有長間隔時，以「上次可確認的練習日期」計算；不能把缺少日誌解讀成確定沒有練習。

## 久未練習時怎麼接續

1. 先看交接、`main.go`、本日誌最後一節和 [進度總表](RECORD.md)，確認最後可查的練習日期與待複習觀念。
2. 相隔 **未滿 14 天**：先用一題舊題做簡短口述，能說清楚思路、正確性、複雜度與邊界就接續原進度。
3. 相隔 **14～29 天**：從已解題挑 **2 題不同題型**做不看筆記的診斷；先口述，再視情況實作其中一題。
4. 相隔 **30 天以上**，或日期不明且使用者自述很久未練：挑 **3 題不同題型**診斷，涵蓋陣列／搜尋、樹／圖、動態規劃等已學內容。一次只進行一題；先獨立嘗試，再按實際卡點給提示。
5. **是否重新練基礎由表現決定，沒有時間一到就全部重做的要求。** 若至少兩種題型連核心觀察或基本實作都無法在提示後完成，先從相應的 Easy 基礎題重新建立，再回到 Medium；若只是單一觀念不穩，針對該觀念複習即可。既有 `Solved` 紀錄不清除；需重做的具體題目標記 `Revisit`，並在日誌寫明原因與下一次檢查點。
6. 診斷結論要記錄實際證據：是否獨立完成、用了多少提示、能否解釋正確性與複雜度。未測試或未口述的能力不可寫成已掌握。
