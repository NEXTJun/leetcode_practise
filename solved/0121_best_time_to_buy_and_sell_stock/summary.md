# 0121. Best Time to Buy and Sell Stock

## 題目

給定每天股價 `prices`，最多進行一次交易，買入日須早於賣出日；回傳最大利潤，沒有正利潤則回傳 0。原題為 Easy。

## 最終解法

```go
func maxProfit(prices []int) int {
    if len(prices) == 0 {
        return 0
    }

    low := prices[0]
    maxP := 0
    for i := 1; i < len(prices); i++ {
        if prices[i] > low {
            if prices[i]-low > maxP {
                maxP = prices[i] - low
            }
        } else {
            low = prices[i]
        }
    }
    return maxP
}
```

## 推導與正確性

逐日固定買入日，再搜尋後面最高賣價，會重複掃描，時間 O(n²)。改為從左到右把今天當賣出日：`low` 保存今天之前最低價，`maxP` 保存此前可達到的最大利潤。對固定賣出日，選先前最低價買入即可使當日利潤最大；每個合法賣出日都檢查一次，故不漏掉全域最優。若今天價格更低，就更新 `low` 供後面的日期使用。`maxP` 初始為 0，因此一路下跌時回傳 0。

## 複雜度

令 n 為天數：時間 O(n)，額外空間 O(1)。沒有遞迴堆疊。

## 面試口述版

走訪每天股價時，保存之前最低買價，將今天當賣出日計算利潤，再與歷史最佳利潤比較。因為當日最低買價給出該賣出日的最佳利潤，而所有賣出日都會被檢查，所以得到全域最佳。時間 O(n)，額外空間 O(1)。
