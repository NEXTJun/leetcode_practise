# 0198. House Robber

## 題目

給定非負整數陣列 `nums`，每個元素是一間房的金額。不能選相鄰兩間，求可得最大金額。Medium。

## 本輪最終解法

```go
func rob(nums []int) int {
	nl := len(nums)
	if nl == 0 {
		return 0
	} else if nl == 1 {
		return nums[0]
	}

	F := make([]int, nl)
	for i := 0; i < nl; i++ {
		if i == 0 {
			F[i] = nums[i]
			continue
		} else if i == 1 {
			F[i] = max(nums[i-1], nums[i])
			continue
		}
		F[i] = max(F[i-1], F[i-2]+nums[i])
	}
	return F[nl-1]
}

func max(n1, n2 int) int {
	if n1 > n2 {
		return n1
	}
	return n2
}
```

## 解法推導

暴力法可對每間房分成拿／不拿，再遞迴列舉；重複子問題很多。`F[i]` 定義為只看索引 0 到 i 的房子時可取得的最大金額。若不拿第 i 間，候選是 `F[i-1]`；若拿，必須跳過第 i-1 間，候選是 `F[i-2]+nums[i]`。取兩者最大。首兩格分別是 `nums[0]` 與 `max(nums[0],nums[1])`；空輸入額外回傳 0。

## 正確性理由

對每個前綴的最佳選法，第 i 間只能是拿或不拿，兩類互斥且涵蓋所有合法選法。不拿時前一前綴可取到的最佳金額為 `F[i-1]`；拿時不能選第 i-1 間，之前可取到的最佳金額為 `F[i-2]`。從基底依序計算，故最後 `F[n-1]` 是全陣列最大金額。此通用證明是整理筆記；使用者目前僅在具體例子中正確計算兩種候選，尚未獨立完整口述。

## 複雜度

令 n 為房子數：時間 O(n)，額外空間 O(n)（DP 陣列）。沒有遞迴堆疊。只需前兩個狀態即可再優化為 O(1) 空間，但本輪尚未獨立實作。

## 面試口述版

定義 `F[i]` 為前 i+1 間房的最大金額。最後一間若不拿，答案來自 `F[i-1]`；若拿，跳過相鄰房，答案為 `F[i-2]+nums[i]`。依序填表後回傳最後一格。時間 O(n)、額外空間 O(n)。
